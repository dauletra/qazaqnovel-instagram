# Qazaqnovel Instagram

Репозиторий контента Instagram Qazaqnovel.kz, не кода сайта (сайт —
`dauletra/qazaqnovel`).

- Любой пост, карусель, сторис, обложка Reels, подпись или месячный план —
  через skill `instagram-post` (`.claude/skills/instagram-post/SKILL.md`).
- Решения владельца (`docs/plan.md`, конец): только казахский язык, без
  эмодзи, аккаунт ведёт один человек с Claude, бюджета нет, Canva не
  используется.
- Владелец вычитывает каждый текст перед публикацией: отдавая пост, называй,
  что проверить (казахский текст, факты, цитаты).
- Опубликованные посты (`status: published`) не перерисовывать.
- С владельцем общаемся по-русски; контент — по-казахски.
